# 股票分析引擎详细指南

> 本文档包含股票分析的完整方法论。SKILL.md 中仅保留流程框架，所有判据细节、估值方法、分析模板在此。

---

## A. 产业链定位

对任何股票，**先定位它在产业链的哪一层，再讨论它值不值钱**。

### 产业链层级模板

```
L0 终端需求   ← 谁在用？需求增速？
L1 系统集成   ← 谁把零件拼成产品？
L2 核心模组   ← 哪个模组最值钱？
L3 关键器件   ← 哪个器件最难做？
L4 工艺/设备  ← 谁提供制造能力？
L5 材料/耗材  ← 什么材料不可替代？
L6 原料/矿产  ← 源头卡在哪？
```

### A股特殊层

- 政策催化层：政府补贴/产业政策/国产替代清单
- 资金结构层：北向资金/融资融券/龙虎榜游资
- 筹码分布层：主力控盘程度/股东人数变化

### 输出格式

```
## 产业链位置
[公司名/代码] 处于 [层级]，具体是 [做什么的]
上游：[谁供应它]
下游：[它供应给谁]
卡点强度：[强/中/弱]，因为 [理由]
A股特色信号：[政策驱动/资金面/筹码面 相关发现]
```

## B. 卡点判断（14条判据）

### 核心6条（每条满足+1信念分）

1. 结构性垄断/双寡头/single point of failure？
2. 市值 vs 下游TAM不对称（Sub-$2B才有10x空间）？
3. designed-in + 多客户（在多条链反复出现）？
4. 认证周期长、当期财报未反映（2027放量=现在错杀）？
5. 资产负债表能活到放量？
6. demand far outstrips supply（大客户全包产能）？

### 扩展8条（每条满足+0.5信念分）

7. BOM占比相对市值巨大 + designed-in
8. 未来（2027-28）爆发营收，当期财务无所谓
9. 大客户把上游产能全包 → 制造卡点
10. 国家安全/CHIPS Act/政府介入
11. Made in China / 国产替代（A股特有加分）
12. 信息不对称/定价错误（市场误分类）
13. 极少数玩家（世界没几家能做）
14. 多年营收可见性/大额backlog已de-risk

### 红旗排除

| 红旗 | A股适配版 | 强度 |
|------|---------|------|
| 无限增发/ATM稀释 | 定增频发、大股东减持不断 | **硬否决** |
| 单一客户集中 | 单一大客户占营收>50% | 高 |
| 资产负债表toxic | ST/*ST、资不抵债 | **硬否决** |
| 零收入纯炒作 | 无主营、靠题材续命 | 高 |
| 大市值已无不对称 | 已充分定价、机构重仓 | 降级 |
| 蹭热点非主营 | 业绩会/互动易喊概念 | 高 |
| 无流动性 | A股日均成交<5000万 | 降级 |

## C. 治理质量评估

在卡点判断之后，逐项检查以下 4 条治理判据：

| # | 判据 | 评估方法 | 红旗信号 |
|---|------|---------|---------|
| G1 | **大股东增减持历史** | 近 3 年大股东/高管增减持记录 | 连续多季度净减持、IPO 解禁后立即减持 |
| G2 | **关联交易占比** | 关联交易/营收比例 | >30% 且持续上升、与大股东控制企业频繁交易 |
| G3 | **交易所信披评级** | 上交所/深交所信息披露评级 | 连续 C 级或 D 级 |
| G4 | **分红稳定性** | 近 5 年分红率/分红金额趋势 | 盈利但连续 2 年以上不分红（成长股可豁免） |

**治理红旗处理**：
- 命中 2 条及以上 → 估值打 9 折
- 命中 3 条及以上 → 估值打 8 折 + 在结论中显式警告
- 交易所信披评级 D → 直接否决，不做进一步分析

## D. 贝叶斯内在增长估值

### 先验概率锚定规则

在设定 H0-H5 六档 CAGR 的先验概率前，**必须先确定基准锚**：

1. **行业基准增速**：取该行业过去 5 年平均营收增速的中位数（来源：行业研究报告或 AnySearch）
2. **公司历史增速**：取该公司过去 3 年营收 CAGR
3. **锚定值** = (行业基准 + 公司历史) / 2
4. **调整逻辑**：
   - 卡点判据命中 ≥ 8 条 → 锚定值上移一档
   - 卡点判据命中 ≤ 3 条 → 锚定值下移一档
   - 治理红旗命中 ≥ 2 条 → 锚定值下移一档

### 概率化假设框架

| 假设 | CAGR区间 | 先验概率 | 核心理由 |
|------|---------|---------|---------|
| H0 衰退型 | <0% | | |
| H1 低速成熟 | 0%-5% | | |
| H2 稳定成长 | 5%-12% | | |
| H3 高景气成长 | 12%-25% | | |
| H4 结构性爆发 | 25%-50% | | |
| H5 平台级扩张 | >50% | | |

计算**加权内在增速**，然后与**市场隐含增速**对比：
- 内在增速 > 隐含增速 → 低估
- 内在增速 ≈ 隐含增速 → 合理
- 隐含增速 > 内在增速 → 高估

### 先验概率必须标注

每一档的先验概率后面必须标注理由，格式为：
```
H3 高景气成长 | 12%-25% | 25% | 行业锚=15%，公司历史CAGR=18%，卡点命中10条上移一档 [先验假设，基于行业均值+历史增速锚定]
```

## E. 市场隐含增速反推（反向 DCF）

对每只核心标的，用简化反向 DCF 计算市场在定价什么增速。

### 计算方法

1. 5年后目标市值 = 当前市值 × (1 + 要求回报率)^5（默认要求回报率=10%）
2. 所需5年后净利 = 目标市值 ÷ 假设终值PE（默认25x）
3. 所需5年后营收 = 所需净利 ÷ 假设成熟净利率
4. 隐含营收CAGR = (所需5年后营收 ÷ 当前营收)^(1/5) - 1

### 输出表格（10列）

| 标的 | 当前市值 | 5年后目标市值 | 所需5年后净利 | 假设净利率 | 所需5年后营收 | 当前营收 | 隐含营收CAGR | 内在合理CAGR | 判断 |
|------|---------|:----------:|:----------:|:--------:|:----------:|--------|:--------:|:--------:|:----:|

### 判断标准

- 隐含CAGR ≤ 内在CAGR × 1.0 → 🟢 合理/低估
- 隐含CAGR 在内在CAGR的 1.0-1.5x → 🟡 略高
- 隐含CAGR > 内在CAGR × 1.5 → 🔴 严重高估
- 隐含CAGR > 内在CAGR × 2.0 → ⚠️ 脱离地心引力

### 净利率假设指引

- 制造业（零部件/设备）：8-15%
- 轻资产科技（软件/IP）：20-35%
- 垄断性卡点（独家供应商）：15-25%
- 整机/系统集成（竞争激烈）：5-10%
- 当标的当前净利率 > 假设值 → 用当前值；当前净利率 < 假设值 → 用假设值

### A股估值特殊工具

- 紧缺卡点股：不用P/E，用同行倍数差 + 历史卡点价格曲线
- 成熟价值股：用forward P/E + EV/FCF
- 超成长股：用forward revenue/ARR ÷ 市值
- 硬阈值：单位数fwd P/E=极便宜；WMT 40PE=贵的反向锚

## F. 估值 Benchmark 三重对比

每个估值结论必须增加三重参照：

| 对比维度 | 数据来源 | 输出格式 |
|---------|---------|---------|
| vs 行业平均 PE | AnySearch + WebSearch 行业对比 | `行业PE中位数=X，标的PE=Y，偏离+Z%` |
| vs 历史 5 年 PE 分位 | WebSearch / AKShare 历史数据 | `当前PE处于过去5年第N百分位` |
| vs 国际对标 PE | AnySearch us_stock | `对标公司A PE=X，标的PE=Y` |

**综合判断**：三者都偏低时才判断为"低估"。仅单项偏低 → "估值合理但XX维度有安全边际"。

## G. 三情景估值

在单点估值之外，输出三情景估值区间：

| 情景 | 概率 | 假设 | 合理估值区间 |
|------|:---:|------|:----------:|
| 🟢 Bull | 20% | [具体乐观假设，如：新产品放量超预期、政策大幅加码] | [X - Y 元/股] |
| 🟡 Base | 60% | [基准假设，基于行业增速+公司历史] | [X - Y 元/股] |
| 🔴 Bear | 20% | [具体悲观假设，如：宏观冲击、竞争加剧、技术替代] | [X - Y 元/股] |

**Bear 情景必须包含至少一个宏观冲击假设和一个行业竞争假设。**

## H. 股东回报分析

| 指标 | 数据来源 | 说明 |
|------|---------|------|
| 股息率 | 最近 12 个月分红 / 当前市值 | >3% 有吸引力 |
| 分红率 | 分红 / 净利润 | >50% 需确认可持续性 |
| FCF 覆盖率 | 自由现金流 / 分红总额 | >1.2x 安全，<0.8x 警惕 |
| 回购记录 | 近 3 年回购金额/频率 | 真金白银的信心信号 |

**对于成长期公司**（营收增速 >20%）：分红不是必须的，资本再投入优先。
**对于成熟期公司**（营收增速 <10%）：不分红且无回购 → 治理问题。

## I. 宏观校准

在给出个股结论前，先回答宏观三问：

1. **现在是什么宏观周期？** 利率方向？流动性收缩还是扩张？
2. **这个板块在宏观下是顺风还是逆风？**
3. **有什么宏观事件可能在未来3-6个月改变估值逻辑？**

## J. 技术执行视角

**⚠️ 长期投资者（持有 3-5 年）可跳过本节——技术面仅影响入场时机微调，不影响核心投资判断。**

对短期入场时机，回答三个问题：

1. **今天是什么市场日？** 趋势日 / 区间日 / 事件日 / 反转日？
2. **量价确认了吗？** 突破有没有量配合？ATR在合理范围吗？
3. **如果错了，止损设在哪？** 入场价-1.5×ATR？

### 技术指标参考（详见 references/a-share-signals.md）

- 均线趋势：MA20/60/120 排列方向
- 成交量验证：放量突破 vs 缩量回调
- 相对强弱：vs 行业指数走势对比
- 市场宽度：涨跌比、新高新低比

## K. Adversarial Review（强制）

在撰写综合结论之前，**必须**执行以下对抗性验证：

### Bull Case（看多逻辑）
- 最乐观情景下，3 年后这家公司值多少？
- 支撑乐观情景的 3 个最强证据是什么？
- 每个证据的数据可信度？

### Bear Case（看空逻辑）
- 最悲观情景下，3 年后可能跌到多少？
- 支撑悲观情景的 3 个最强证据是什么？
- 哪些信号出现意味着 bear case 在兑现？

### 综合结论要求
**必须回应 bear case 中最强的 3 个论点**，不能只列不论。

```
**产业链位置**：[层级] / 卡点强度：[强/中/弱]

**治理评估**：[G1-G4 判据命中情况] / 打折系数（如适用）
**红旗检查**：[无 / 命中：X条]

**三情景估值**：Bull [X-Y] / Base [X-Y] / Bear [X-Y]
**Benchmark 对比**：vs 行业 [X] / vs 历史分位 [N%] / vs 国际对标 [X]
**宏观顺风**：[是/否/不确定]
**时机判断**：[适合建仓/等待/减仓/观望]

**一句话结论**：[...]

**什么情况会推翻**：[证伪条件]
```
