## AnySearch + WebSearch 分工协作

### 实测对比结论

| 数据层 | AnySearch 表现 | WebSearch 表现 | 结论 |
|--------|:--:|:--:|------|
| 行业新闻/IPO动态/出货排名 | ✅ 强 | ❌ 弱 | AnySearch |
| 公司叙事（营收公告、订单） | ✅ 强 | ❌ 弱 | AnySearch |
| 政策文件细节 | ✅ 强 | ❌ 弱 | AnySearch |
| A股结构化财务（市值/PE/营收） | ❌ 弱（覆盖率19%） | ✅ 强（覆盖率100%） | WebSearch |
| 多标的横向估值对比 | ❌ 弱 | ✅ 强 | WebSearch |
| 非上市公司信息 | ✅ | ❌ | AnySearch |

## AnySearch 核心能力矩阵

| 能力 | 分工角色 |
|------|---------|
| `domain: finance` + `zone: cn` | 行业新闻、公司叙事、出货排名、IPO动态 |
| `batch_search`（2-5路并行） | 产业链 L0-L6 各层同时查 |
| `extract`（URL → Markdown） | 抓取东方财富个股页/研报全文 → 回填结构化数据缺口 |
| `domain: finance, sub_domain: finance.us_stock` | 美股对标估值查询 |
| `domain: academic` | 技术壁垒/专利/学术论文验证 |
| `domain: security` | 供应链安全/CVE 查询 |

```
需要搜索什么？
│

│   ├── 公司叙事（营收公告/订单/重大合同/扩产）
│   │   └── domain=finance, sub_domain=finance.cn_stock, zone=cn
│   ├── 宏观经济（利率/CPI/PMI/政策/社融）
│   │   └── domain=finance, sub_domain=finance.macro, zone=cn
│   ├── 政策/行业新闻（补贴/标准/监管/地缘）
│   │   └── domain=news, zone=cn
│   ├── 基金（净值/持仓/经理/排名）
│   │   └── domain=finance, sub_domain=finance.fund, zone=cn
│   ├── 美股/港股对标估值
│   │   └── domain=finance, sub_domain=finance.us_stock / finance.hk_stock
│   ├── 学术/专利（技术壁垒验证）
│   │   └── domain=academic
│   └── 供应链安全（地缘风险/CVE/制裁）
│       └── domain=security
│
├── WebSearch：结构化财务数据
│   ├── A股标的市值/PE/营收/净利润/毛利率/ROE/Q1增速（逐只查询）
│   └── 配合 AnySearch 双引擎交叉验证
│
└── AnySearch extract：财务数据回填
    └── 东方财富/同花顺个股页面 extract → 补全表格空值
```

## Batch Search：产业链并行分析

用 `batch_search` 一次性发出 5 路并行查询：

```
以 600519 贵州茅台为例（第1轮：行业全景）：

batch_search([
  { query: "白酒行业 2026 竞争格局 高端白酒 茅台 五粮液 泸州老窖", domain: "finance", sub_domain: "finance.cn_stock", zone: "cn" },
  { query: "高端白酒 批价 渠道库存 2026年二季度", domain: "news", zone: "cn" },
  { query: "2026年6月 中国消费 社零数据 CPI 宏观政策", domain: "finance", sub_domain: "finance.macro", zone: "cn" },
  { query: "白酒产业链 上游 高粱 包材 基酒 下游经销商", domain: "finance", sub_domain: "finance.cn_stock", zone: "cn" },
  { query: "白酒板块 资金流向 北向资金 融资融券 2026", domain: "finance", sub_domain: "finance.cn_stock", zone: "cn" },
])
```

## WebSearch 标准化财务查询模板

每只标的的 WebSearch 查询必须覆盖以下 **8 个字段**：

```
"【标的简称】 【代码】 市值 PE(TTM) 2025营收 2025净利 毛利率 2026Q1营收同比 ROE"
```

| 字段 | 用途 |
|------|------|
| 市值 | 基础估值 |
| PE(TTM) | 横向对比 |
| 2025营收 | 隐含CAGR基数 |
| 2025净利 | PE交叉验证（市值÷净利） |
| 毛利率 | 竞争格局恶化信号、净利率假设支撑 |
| 2026Q1营收同比 | 判断增速在加速还是减速 |
| 近3年毛利率趋势 | 区分单季噪音 vs 趋势性下滑 |
| ROE | 辅助红旗检查（资产负债表健康度） |

## 双引擎对比评估规则

仅适用于**一级数据**（市值、PE、营收、净利润）。

| 状态 | 条件 | 处理方式 | 置信度 |
|------|------|---------|:------:|
| 一致 | 两源差距 < 10% | 取均值，标注 `[双引擎验证：WS+AS]` | 🟢 |
| 小幅偏差 | 两源差距 10%-30% | 取较新源，标注差异 | 🟡 |
| 大幅偏差 | 两源差距 > 30% | **不取值**，两源数据都标注，进入「待确认事项」 | 🔴 |
| 单源 | 仅一源有数据 | 取该源值，标注 `[单源：WS/AS]` | 🟡 |
| 双缺 | 两源均无 | 填入 `待查 [东方财富]`，触发 extract 回填 | — |

## 第 3 轮定向验证触发规则

**分级触发阈值**：

| 数据级别 | 触发阈值 | 示例 |
|---------|:------:|------|
| 一级数据（市值/PE/营收/净利） | 双引擎差异 > **20%** | 市值 WS=380亿, AS=500亿 → 触发 |
| 二级数据（出货量/BOM占比/市场份额） | 多源差异 > **50%** | 出货量 A源=1.5万, B源=3万 → 触发 |
| 三级数据（推断/计算值） | 不触发额外查询 | 始终标注 `[推断]`，不做第3轮验证 |

**触发动作为**：
- 口径冲突 → AnySearch + WebSearch 并行仲裁，取最权威来源
- 推断支撑 → AnySearch extract 抓取最新年报/调研纪要

**约束**：
- 上限 5 条查询，防止无限验证
- 优先级：影响结论方向的 > 仅影响精度的
- 不重复第 2 轮已双引擎确认的数据
- 验证后仍不确定 → 保留在待确认事项，不做第三次查询

## 数字合理性 Sanity Check

在双引擎验证之外，增加以下自动化合理性检查：

### 1. PE 交叉验证
```
计算PE = 市值 ÷ 净利润
如果 |计算PE - 搜索PE| / 搜索PE > 20% → 标记 "PE不一致 [计算=X, 搜索=Y]"
```

### 2. 财务指标勾稽关系
```
净利率 = 净利润 ÷ 营收
如果 毛利率 < 净利率 → 数据异常（毛利率应 > 净利率）
如果 ROE 与 (净利率 × 资产周转率 × 杠杆) 偏差 >50% → 标记
```

### 3. 增速范围检查
```
单季营收同比增速 > 500% → 标记（可能为并购/资产注入等一次性事件）
单季营收同比增速 < -90% → 标记（可能为ST/停业等极端情况）
```

### 4. 异常标记处理
- 任一 sanity check 触发 → 标注 `[sanity check 异常：具体描述]`
- 不阻塞分析流程，但必须在「待确认事项」中列出
- 置信度降为 🟡

## 搜索质量规范

| 规则 | 说明 |
|------|------|
| **先发现子域** | 首次使用 finance 域前，先调用 `list_domains("finance")` |
| **zone 必填** | A股/中国数据必须指定 `zone: "cn"` |
| **batch_search ≤ 5** | 每次并行最多 5 条查询 |
| **数据源强制留存** | 每次 search/extract 后立即追加 URL 到临时列表，写文件前检查数量 ≥ 实际搜索次数 |
| **分工纪律** | 一级数据 → 双引擎并行；行业新闻/出货排名/公司叙事 → AnySearch 单引擎 |

## 防污染规则

| 易混淆类型 | 必须加限定词 |
|-----------|------------|
| 人形机器人出货量 | "人形机器人" NOT "工业机器人" NOT "服务机器人" |
| 谐波减速器市场 | "谐波减速器" NOT "RV减速器" NOT "行星减速器" |
| 人形机器人 BOM | "人形机器人" "BOM成本" |
| 行星滚柱丝杠 | "行星滚柱丝杠" "人形机器人" |

**搜索后 sanity check**：如果返回的数据和历史认知/其他来源偏差 >100%，必须做一次交叉验证。

| 数据类型 | 最大允许滞后 | 标注要求 |
|---------|:----------:|---------|
| 市值 | T日（当日） | `[市值日期：YYYY-MM-DD]` |
| PE(TTM) | T+1日 | `[PE日期：YYYY-MM-DD]` |
| 营收/净利润 | 最近季报 | `[财报截至：YYYY-MM-DD]` |
| 出货量 | 最近公开数据 | `[数据发布时间：YYYY-MM]` |
| 政策文件 | — | `[文件发布日期/文号]` |

## 典型分析场景搜索方案

| 分析类型 | 搜索方案 |
|---------|---------|
| 单股分析 | AnySearch batch_search（5路）+ 双引擎并行（WS+AS，8字段） |
| 赛道扫描 | 三阶段：第1轮 AnySearch batch_search → 第2轮 双引擎并行（核心6-8只）→ 第3轮 定向验证（条件触发） |
| 基金穿透 | AnySearch batch_search（持仓+经理+排名）+ 双引擎并行（重仓股，8字段） |
| 宏观校准 | 1× AnySearch search（利率/流动性/政策）+ 1× WebSearch（宏观经济指标） |
| 快速问 | 1× search（单条精准查询） |
| 对比分析 | 双标的各自单股分析流程并行 + 交叉对比 |
