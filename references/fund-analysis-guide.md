# 基金分析参考指南

## 公募基金分类与分析方法

### 1. 股票型基金（权益类）

**分析重点**：底层持仓穿透 > 基金经理 > 费率

穿透步骤：
1. 获取最新季报的前10大重仓股
2. 对每只重仓股运行股票分析引擎（产业链定位+卡点判断+估值）
3. 统计行业分布和产业链暴露
4. 判断集中度风险

**关键指标**：
- 年化收益率（1/3/5年）
- 最大回撤
- 夏普比率
- 信息比率（vs 基准）
- 超额收益来源（选股 vs 行业配置 vs 择时）

### 2. 混合型基金

额外关注：
- 股债配比变动趋势
- 经理的资产配置能力（vs 选股能力）
- 极端市场下的表现（2018、2022、2024）

### 3. 指数型基金/ETF

**分析重点**：跟踪误差 + 指数基本面

跟踪误差分析：
- 日均跟踪偏离度
- 年化跟踪误差
- 折溢价情况

指数基本面分析：
- 用产业链引擎扫描指数成分股
- 判断指数在产业链周期的位置
- 估值分位（PE/PB历史分位）

### 4. 债券型基金

- 久期分析
- 信用评级分布
- 杠杆水平
- 当前利率环境下的适配性

### 5. QDII基金

- 底层海外资产分析
- 汇率风险敞口
- 申赎效率（T+N）

## 基金定投回测方法

### 回测参数
- 回测周期：建议>5年（覆盖牛熊）
- 定投频率：每周/双周/每月
- 定投金额：等额定投 vs 智能定投（估值分位调整）

### 关键输出
- 年化收益率（IRR）
- 最大回撤
- 回本周期（最长连续亏损月数）
- vs 一次性投入对比
- vs 同类基金/基准对比

### 智能定投逻辑
```
估值分位 < 20% → 2x金额
估值分位 20-40% → 1.5x金额
估值分位 40-60% → 1x金额
估值分位 60-80% → 0.5x金额
估值分位 > 80% → 暂停定投，考虑止盈
```
