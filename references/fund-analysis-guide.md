# 基金分析参考指南

## 公募基金分类与分析方法

### 1. 股票型基金（权益类）

**分析重点**：底层持仓穿透 > 基金经理 > 费率

穿透步骤：
1. 获取最新季报的前10大重仓股
2. 对每只重仓股运行股票分析引擎（产业链定位+卡点判断+估值）
3. 统计行业分布和产业链暴露
4. 判断集中度风险

**关键指标**：
- 年化收益率（1/3/5年）
- 最大回撤
- 夏普比率
- 信息比率（vs 基准）
- 超额收益来源（选股 vs 行业配置 vs 择时）

### 2. 混合型基金

额外关注：
- 股债配比变动趋势
- 经理的资产配置能力（vs 选股能力）
- 极端市场下的表现（2018、2022、2024）

### 3. 指数型基金/ETF

**分析重点**：跟踪误差 + 指数基本面

跟踪误差分析：
- 日均跟踪偏离度
- 年化跟踪误差
- 折溢价情况

指数基本面分析：
- 用产业链引擎扫描指数成分股
- 判断指数在产业链周期的位置
- 估值分位（PE/PB历史分位）

### 4. 债券型基金

- 久期分析
- 信用评级分布
- 杠杆水平
- 当前利率环境下的适配性

### 5. QDII基金

- 底层海外资产分析
- 汇率风险敞口
- 申赎效率（T+N）

## 基金定投回测方法

### 回测参数
- 回测周期：建议>5年（覆盖牛熊）
- 定投频率：每周/双周/每月
- 定投金额：等额定投 vs 智能定投（估值分位调整）

### 关键输出
- 年化收益率（IRR）
- 最大回撤
- 回本周期（最长连续亏损月数）
- vs 一次性投入对比
- vs 同类基金/基准对比

### 智能定投逻辑
```
估值分位 < 20% → 2x金额
估值分位 20-40% → 1.5x金额
估值分位 40-60% → 1x金额
估值分位 60-80% → 0.5x金额
估值分位 > 80% → 暂停定投，考虑止盈
```

## 组合风险分析

> 当用户要求"看看我的持仓"或进行组合分析时，在逐只穿透之外，必须输出以下组合层面的风险指标。

### 1. 行业暴露热力图

按持仓权重 × 行业分类，输出行业集中度：

```
| 行业 | 持仓占比 | 基准占比 | 超配/低配 |
|------|:------:|:------:|:------:|
| 消费 | 35% | 20% | +15% ⚠️ 超配 |
| 科技 | 25% | 30% | -5% |
| 金融 | 10% | 15% | -5% |
...
```

**判断**：单一行业 > 30% → 集中度偏高；单一行业 > 50% → 显著集中风险。

### 2. 持仓相关性矩阵

基于近 2 年周收益率计算持仓标的之间的相关性：

```
|       | 标的A | 标的B | 标的C | 标的D |
| 标的A | 1.00  | 0.65  | 0.30  | 0.15  |
| 标的B |       | 1.00  | 0.40  | 0.20  |
| 标的C |       |       | 1.00  | 0.55  |
```

**判断**：
- 相关性 > 0.7 → 高度相关，分散效果差（相当于同一笔赌注）
- 相关性 < 0.3 → 良好分散
- 平均相关性 > 0.5 → 组合分散度不足

### 3. 集中度风险

| 指标 | 计算方式 | 警戒线 |
|------|---------|:------:|
| 前 3 大持仓占比 | Top3 持仓 / 总资产 | >40% |
| 前 5 大持仓占比 | Top5 持仓 / 总资产 | >60% |
| 最大单只占比 | 单一标的 / 总资产 | >20% |

### 4. 风格暴露

| 维度 | 判断方法 |
|------|---------|
| 大小盘 | 持仓平均市值 vs 沪深300（大盘）/ 中证1000（小盘） |
| 价值/成长 | 持仓平均 PE vs 行业平均 |
| 质量 | 持仓平均 ROE |
| 波动率 | 持仓平均 Beta |

### 5. 组合风险总结模板

```
## 组合风险诊断

**行业集中度**：[均衡/偏高/显著集中] — [具体分析]
**相关性**：[良好分散/分散不足] — 平均相关性 [X]
**集中度风险**：[低/中/高] — Top3 占 [X%]
**风格暴露**：[大盘/小盘/混合] × [价值/成长/混合]

**主要风险点**：
1. [最大风险]
2. [次要风险]

**优化建议**：
1. [具体建议]
2. [具体建议]
```
