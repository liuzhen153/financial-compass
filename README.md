# Financial Compass · 金融指南针

> 用产业链瓶颈理论 + 贝叶斯估值，做长期投资研究。

## 核心理念

Financial Compass 是一个**个人长期投资研究引擎**，不是荐股工具。它帮你建立判断能力，而不是给你"财富密码"。

## 能力

| 模块 | 功能 |
|------|------|
| **股票分析** | 产业链 L0-L6 定位 → 14 条卡点判据 → 贝叶斯内在估值 → 宏观校准 → 技术时机 |
| **基金分析** | 分类识别 → 底层持仓穿透 → 经理评估 → 定投方案 → 费率长期侵蚀 |
| **赛道扫描** | 产业链全景 → 卡点层定位 → 候选标的筛选 → 反向 DCF 隐含增速 → 剩余不对称 |
| **多重验证** | 双引擎交叉验证（AnySearch + WebSearch）→ 三级置信度标注 → 生成前 14 项检查 |

## 方法论来源

整合提炼自 8 个开源金融分析项目，包括：
- Serenity 产业链瓶颈理论
- Bayesian Intrinsic Growth Valuation
- A 股市场特殊信号分析

## 输出

每次完整分析输出一份带 YAML 元信息的 `.md` 文件，格式规范、可回溯、可迭代。
